# Display font

The font used for the editor is zap-vga16.psf 8x16, a VGA font modified and
upgraded by the ZAP Group Australia.

The bitmaps containing 256 glyphs are stored bit-reversed to match the
rendering protocol of the display.
 
https://www.zap.org.au/projects/console-fonts-zap/
